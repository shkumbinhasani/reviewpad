# Brand icons

The SVGs here come from [Simple Icons](https://simpleicons.org), whose icon
files are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
— no attribution is required, but it is recorded here anyway.

The marks themselves remain the trademarks of their respective owners. They are
used only to identify which agent wrote a review comment, which is nominative
use; ReviewPad is not affiliated with, endorsed by, or sponsored by any of them.

Each file is a single monochrome path, because gpui paints an SVG as a mask
tinted with the element's text color — a multi-color logo would flatten to a
silhouette anyway.
